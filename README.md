# 💍 שידוכים Studio - מערכת ניהול מאגר שידוכים והתאמות פרימיום

מערכת ווב יוקרתית, מינימליסטית ומודרנית בעיצוב **Apple**, בעברית מלאה (RTL), לניהול מאגר מועמדים לשידוכים (בחורים ובחורות), סינון והתאמות, ומעקב שלבי פגישות וציר זמן בזמן אמת.

---

## ✨ תכונות מרכזיות

1. **עיצוב Apple פרימיום ומינימליסטי (RTL)**:
   - טיפוגרפיית San Francisco / Heebo אלגנטית
   - זכוכית מעורפלת (Frosted Glass), גלאסמורפיזם ופינות מעוגלות מדויקות
   - תמיכה מלאה במצב בהיר / מצב כהה (Dark / Light Mode)
   - אנימציות עדינות ומיקרו-אינטראקציות רכות

2. **מאגר מועמדים עשיר (בחורים 👨 ובחורות 👩)**:
   - כל השדות הנדרשים כפי שצוין בבקשה:
     - שם מלא, מגדר, עדה (מרוקאי, עיראקי, אשכנזי וכו')
     - גיל, גובה (למשל 1.72 מ׳), מבנה כללי, מצב משפחתי, עיר מגורים
     - השקפה דתית, שומר/ת נגיעה, מעשן/ת, סוג טלפון (כשר / מסונן / חכם)
     - שירות צבאי / לאומי / ישיבה, עיסוק ושאיפה לעתיד, תיאור המשפחה
     - קצת עלי (אופי, שאיפות וערכים), מה אני מחפש/ת בבן/בת הזוג
     - טלפון ליצירת קשר, רבנים וממליצים לבירור
     - **הערות שדכן פנימיות חסויות** (אינן מופיעות בכרטיס המודפס)
   - חיפוש מהיר וסינון מתקדם לפי גיל, גובה, השקפה, עיר, עדה וסטטוס זמינות
   - צפייה בכרטיס מלא, עריכה ומחיקה קלה בלחיצת כפתור
   - כפתור **"הדפסה / PDF"** מעוצב להדפסת כרטיס שידוכים נקי לחלוקה

3. **לוח שידוכים ומעקב פגישות (Matchmaking Pipeline)**:
   - יצירת שידוך בין בחור ובחורה מתוך המאגר
   - כפתור ישיר "💍 הצע שידוך" מתוך כרטיס המועמד
   - שלבי מעקב (Kanban & List):
     - 💡 רעיון ראשוני / בבדיקה
     - ⏳ ממתין לתשובת הבחור
     - ⏳ ממתין לתשובת הבחורה
     - 🤝 אושר להחלפת פרטים / פגישה
     - ☕ פגישה 1
     - ☕ פגישה 2
     - 🌟 פגישה 3+
     - 🚀 מתקדם ברצינות
     - 💍 מאורסים! (מזל טוב!)
     - ❌ ירד מהפרק / לא התאים (עם פירוט סיבה)
   - **יומן פגישות וציר זמן**: תיעוד תאריכי פגישות, רשמים, אתגרים שעלו, המלצות לשלב הבא והיסטוריה מלאה של הזוג.

4. **אבטחה והתחברות**:
   - התחברות עם שם משתמש וסיסמה מוצפנת ב-PBKDF2-SHA256
   - ניהול סשנים מאובטח

## 🚀 הפעלה מהירה ב-macOS

### אפשרות 1: לחיצה כפולה (מומלץ)
פשוט לחץ לחיצה כפולה על הקובץ:
```
start.command
```
השרת יופעל והדפדפן ייפתח אוטומטית על `http://localhost:8080`.

### אפשרות 2: דרך הטרמינל
פתח טרמינל בתיקיית הפרויקט והרץ:
```bash
./run.sh
```
או ישירות:
```bash
python3 server.py
```
ופתח בדפדפן: `http://localhost:8080`
